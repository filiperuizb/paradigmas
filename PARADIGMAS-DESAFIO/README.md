## DESAFIO - TRATAMENTO DE EXCECOES (VALORANT)

--

* Arquivos Java: SistemaValorant.java e LojaService.java

Compilar: javac SistemaValorant.java LojaService.java
Execucao normal: java SistemaValorant
Execucao com falha: java SistemaValorant falha

O valor de VP e simulado, nao representa cotacao atual da loja.
O programa consulta precos, nao realiza compras.
